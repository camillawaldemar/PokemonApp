# Pokemon

- Live website: https://camillawaldemar.github.io/PokemonApp/
- Public GitHub repository: https://github.com/camillawaldemar/PokemonApp

## Versions

While working on the case, I ended up with three versions of the site. The first two only showed 721 of the 811 Pokémon, because the alternate forms, like the mega evolutions, have no image in the CSV and were left out. The point of the case was to show all 811, so the alternate forms should have been included. A third version was made to include them. On the final site the images come from PokéAPI, so the forms without an image in the CSV also get a picture. The first two versions are archived on GitHub.

## Time spent

About 4 to 5 hours in total, over two days. On day one, I built the site with Claude and published it on GitHub Pages. On day two I went through it again, checked it against the assignment and the data, fixed some small text errors and prepared the submission.

## Cost

The only cost was my Claude subscription. Hosting on GitHub Pages is free, the data was part of the case, and PokéAPI is free to use.

I used a paid Claude Pro plan, which costs 22.50 EUR (around 170 DKK) a month. I don't know exactly how much of my usage limit the case used, but since I worked on it for two days, my estimate would roughly be 4-7% of the monthly price (around 1-1.5 EUR).

Claude wrote the code (HTML, CSS, JavaScript and a Python script that converts the CSV) and helped check that all 811 pages work. I decided what the site should do, checked the results against the assignment and the data, compared the versions, chose the final one and published it.
